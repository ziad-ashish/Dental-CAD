📡 Scanner Folder Watch

Watches a local folder for new scan files (.STL, .OBJ, .PLY). When a scanner saves a file to that folder, DentalCAD will detect and import it automatically — simulating direct scanner integration.
Requires Chrome / Edge 86+ (File System Access API). Real-time integration requires scanner SDK from the manufacturer.

Status: Idle — click Start to pick a folder.
